# Golden set

`off_us_sample.parquet` holds 3,000 US products from the Open Food Facts CSV export
(2026-10-12), with the columns `pipeline/off_bulk.py` keeps. It is used to check that our
Nutri-Score grades match Open Food Facts' own (spec 015).
